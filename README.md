# DocuMaster PDF Extractor 📄🚀

Este projeto é uma ferramenta robusta em Python para a extração de texto de arquivos PDF, permitindo a leitura total ou de páginas específicas.

## 🛠️ Funcionalidades
- **Leitura Completa:** Extrai todo o conteúdo de texto do PDF.
- **Leitura Seletiva:** Permite escolher páginas específicas para extração.
- **Tratamento de Erros:** Identifica arquivos inexistentes ou protegidos por senha.

## 🔧 Tecnologias Utilizadas
- [Python 3](https://www.python.org/)
- [pypdf](https://pypi.org/project/pypdf/)
- [Git/GitHub](https://github.com/)
